Common questions

Which files does it open?

Lowrance .usr files (formats 4–6, tested on files exported from an Elite FS 9), GPX, KML and KMZ.

How do I get the file back onto my Lowrance?

Export from CourseKit and unzip the download. Copy the .usr file to the GPS's memory card. On the unit, delete all waypoints first (it skips any waypoint it already has), then import the file.

Where do race miles come from?

CourseKit measures each waypoint along the course line in your file and lines the result up with the SCORE "RM" mile markers when the file has them.

How are the automatic corner calls made?

CourseKit measures how tight each bend on the course line is and how far it turns. The L1–L6 grades were matched against a pace-note team's calls. They are estimates from the course line: check them on a pre-run before relying on them.

Does it work offline?

Yes, after it has been opened once. Map backgrounds need a connection, but areas you have already viewed are kept on the device.

Why does voice recording stop?

Speech recognition only runs while CourseKit is open on screen. Keep the phone mounted with the screen on. If listening stops, tap the banner to start it again.

Safety

CourseKit is a tool for preparing notes. Courses change and GPS lines are approximate. Always pre-run, drive to the conditions and race at your own risk.
